# Distribution and version scope

The skill owner can install and save this skill in ChatGPT Work. Sharing is performed by the user in the Skills directory. Never report workspace rollout as complete just because personal installation succeeded.

For organisation rollout: open Plugins > Skills, select Incentive Games Design System and use Share to grant the Incentive Games workspace or its relevant groups access. Have an administrator enable the available workspace skill distribution/installation controls. Where installation for other members is supported and authorised, use that; otherwise each member installs the shared skill once. Verify from a colleague's account with a fresh game-building request that the skill and its bundled assets are available without explicitly invoking it.

This package sets allow_implicit_invocation:true and broad game-building/editing triggers. That supports automatic selection but is not a platform-level enforcement guarantee. Project-local AGENTS.md plus the copied rules provide another entry point. Build validation supplies actual checks.

Do not depend on the owner's private chat, personal Library IDs, expiring asset URLs or private code paths when colleagues reuse the skill. The approved core references and tokens are included. A connected Figma account is needed only for unbundled variants or deliberate updates.

Installing or updating the skill does not change already-published games. Apply it to the specific game project when that project is worked on. For a requested bulk migration, enumerate the authorised projects, preserve their source and behaviour, update and verify each, and use their normal deployment process. Do not silently deploy every historic game.

Maintain one exact skill. For a requested company-wide revision, update the approved references/resources, increment the baseline version and verify distribution. Do not assume updates have reached every installed copy without checking. Explicit per-game exceptions belong in that project's exceptions file, not in this global baseline.
