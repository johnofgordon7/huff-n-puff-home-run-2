## Incentive Games design system

Apply the installed `incentive-games-design-system` skill automatically when building,
editing or reviewing this game. If unavailable, read
`docs/incentive-games/references/rules.md` and
`docs/incentive-games/references/implementation.md` before changing the UI.
Use the bundled tokens and original vector assets, plus the appropriate visual reference.
Baseline version: 1.0.0. See `docs/incentive-games/manifest.json`.

Keep the game within its available viewport with no page scrolling; keep header and
footer persistent, play centred, the game area adaptive, and stake selection an overlay
with an internally scrolling three-column grid. Preserve game behaviour and supported
features. Use the compact reference on small screens. Never render fake phone/browser
chrome from the reference screenshots. Follow
`docs/incentive-games/references/acceptance.md` before delivery.
Record explicit per-game deviations in `docs/incentive-games/project-exceptions.md`.
Do not silently alter the shared baseline or publish unrelated games.
